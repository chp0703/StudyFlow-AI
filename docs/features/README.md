# Feature map

StudyFlow AI contains three first-class product features. They share authentication, authorized materials and orchestration, while retaining separate domain ownership.

| Feature | Responsibility | Current documentation |
|---|---|---|
| Intelligent Academic Planner | Tasks, working time, scheduling, proposals and approval | [planner/](planner/) |
| Learning Assessment & Adaptive Revision | Verified quizzes, deterministic grading and revision recommendations | [assessment/README.md](assessment/README.md) |
| Daily AI Learning | Source-grounded explanations, hints and confirmed session outcomes | [daily-learning/README.md](daily-learning/README.md) |

The complete cross-feature scope is defined in [product requirements](../product/requirements.md).
