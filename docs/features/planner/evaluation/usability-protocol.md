# Planner usability protocol

## Participants and safety

- Target 20 university students; minimum 12. Report the actual number and recruitment limits.
- Use anonymous participant IDs and the supplied synthetic study scenario.
- Do not collect passwords, real grades or real calendars. Participation is voluntary and may stop at any time.

## Tasks

1. Set Monday working time to 09:00–22:00.
2. Create a 90-minute high-priority task due Friday.
3. Ask Planner to generate a weekly schedule.
4. Inspect the confirmation view and identify one conflict or unscheduled item.
5. Approve the proposal only after checking its details, then locate the resulting study block.

The facilitator must not coach the participant after reading a task. Start timing when the task is read and stop on success, abandonment or five minutes.

## Measures

- Binary task completion using the expected final state.
- Time-on-task in seconds and observable error count.
- Whether the participant understood that chat does not itself approve a mutation.
- Standard ten-item System Usability Scale (SUS), alternating positive and negative statements on a 1–5 scale.
- One open question: “Điều gì trong lịch hoặc bước xác nhận khiến bạn khó hiểu nhất?”

SUS scoring: subtract 1 from odd-item responses, subtract even-item responses from 5, sum and multiply by 2.5. Report raw responses, median, mean and range; do not label a score “good” without naming a comparison source.
