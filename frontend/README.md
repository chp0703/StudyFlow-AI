# StudyFlow AI

React prototype of a student study workspace (dashboard, planner, study session, review, materials). Demo only: no backend, auth, persistence, file parsing or live AI.

```bash
npm install
npm run dev      # http://localhost:5173 (or $PORT)
npm run build
npm run preview
npm run format
```

Team conventions and architecture: see [DESIGN.md](DESIGN.md).
